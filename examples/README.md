# 示例目录

这里展示“输入 → Enough 输出”的真实或脱敏示例。它们用于说明复用决策、现有代码库扩展和长任务验收，不是每个软件任务的固定流程。

- [reuse-decision-rss-guard.md](reuse-decision-rss-guard.md)：**v0.2 当前示例**——真实产品选型时，发现成熟项目完全满足需求，零行代码采用，而不是自建。
- [existing-codebase-feature.md](existing-codebase-feature.md)：**v0.1 历史材料**——保留当时的代码考古与外部调研过程；v0.2 对已有代码库的局部扩展先查本地能力，只有真正选型才外部搜索。
- [new-project-build.md](new-project-build.md)：**v0.1 历史材料**——保留一次新项目的复用决策和闭环定义；v0.2 不要求固定候选数量、固定步骤或所有任务的纵向闭环。
- [mind-journal-end-to-end.md](mind-journal-end-to-end.md)：**v0.1 历史材料**——保留一次复杂长任务如何重评、分阶段设计、闭环和验收；v0.2 只在复杂设计和真实跨边界系统时采用相称部分。

当前行为以 [skills/enough/SKILL.md](../skills/enough/SKILL.md) 为准：先按 FAST / NORMAL / DEEP 分级，优先复用已有能力，只在真正选型时外部搜索；设计、永久测试和 TDD 都按具体风险与证据决定。
